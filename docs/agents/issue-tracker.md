# Issue tracker: Local Markdown

Issues and specs live under `.scratch/`.

- One feature per directory: `.scratch/<feature-slug>/`
- Specification: `.scratch/<feature-slug>/spec.md`
- Implementation tickets: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Record status in a `Status:` line near the top.
- Append discussion under `## Comments`.

When asked to publish a spec or issue, create the corresponding local file.
When asked to fetch one, read the path supplied by the user.
