# Worker → Reviewer → Core

The current shared Goal/Ralph lifecycle has no separate evaluator. Worker implements the user's task and runs ordinary tests. Independent Reviewer sees those results and assesses only remaining judgment questions and concrete defects. Core validates the existing action/criterion schema, identities, scope, dependencies, progress and budgets and chooses the next transition.

Initial recorded task authority permits work without a model preflight. Review follows an actual Worker result or concrete recovery/human/resource event, not mandatory pre/post loops. No generated eval.py, evaluator source repair or unknown-to-experiment conversion. Concrete corrections use the existing action/attempt/experiment path within the same cumulative Worker budget. Unknown checks remain unknown; independent authorized work and result delivery continue despite missing review.

Delivery is not acceptance. Core finish still requires reconciled effects, independently assessed cycles, complete actions, all criteria pass and resolved blockers. Worker ready/exit0/native lifecycle and Reviewer endorse alone cannot establish finish. Reviewer/headless identity and finite budget stay separate from Worker; durable delivery, ownership and no-ambiguous-replay protections stay intact.
